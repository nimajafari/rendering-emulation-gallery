CSS media features

Real CSS features, emulated via DevTools' Emulate CSS media feature dropdowns and detectable in JS via matchMedia. Each page reads and displays your browser's actual live setting.

Vision deficiency emulation

DevTools' Emulate vision deficiencies dropdown is a display filter applied over the whole rendered page. There is no CSS media feature or JS API for it — these pages can't detect or react to it, so each one shows a bad pattern stacked above a good pattern for a human to compare while toggling the filter.
