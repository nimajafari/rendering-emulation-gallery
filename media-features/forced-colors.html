forced-colors

Detects when the browser is overriding author colors with a user- or OS-defined limited palette (e.g. Windows High Contrast Mode), so a page can add back structure that color alone used to provide.

Checking…
Try it: open Chrome DevTools → More tools → Rendering → Emulate CSS media feature forced-colors, then switch between none and active. The banner above updates live — and DevTools will also repaint colors using the system's forced palette.
Ignores the preference Respects the preference

Borderless status pill

Both pills rely on background color alone by default. In forced-colors mode, backgrounds are flattened by the browser — only the right pill adds an explicit border so it stays visible as a distinct shape.

Active
Active 
.chip.a, .chip.b {
  background: #5fc9a8;
  color: #0e1013;
  border: 1px solid transparent;
}

@media (forced-colors: active) {
  .chip.b {
    border: 1px solid CanvasText;
  }
}

Focus ring on a custom control

Custom outlines are also stripped by forced-colors. The right control explicitly re-declares its outline using the Highlight system color so keyboard focus stays visible.

.ctrl.a, .ctrl.b {
  outline: none;
  box-shadow: 0 0 0 2px #5fc9a8;
}

@media (forced-colors: active) {
  .ctrl.b {
    outline: 2px solid Highlight;
    box-shadow: none;
  }
}
Browser support: Chrome/Edge 89+, Firefox 113+, Safari 17.4+ (values: none, active).
