prefers-color-scheme

Detects whether the visitor's system is set to a light or dark color scheme, so a page can adapt its palette automatically.

Checking…
Try it: open Chrome DevTools → More tools → Rendering → Emulate CSS media feature prefers-color-scheme, then switch between light and dark. The banner above updates live.
Ignores the preference Respects the preference

Card background & text

Both cards render identically with no preference set. Only the right card switches to a dark palette under prefers-color-scheme: dark.

Card content stays light regardless of system setting.
Card content follows your system's color scheme.
.card.a, .card.b {
  background: #f4f4f5;
  color: #16181c;
  border: 1px solid #d8d8dc;
}

@media (prefers-color-scheme: dark) {
  .card.b {
    background: #1c1e22;
    color: #eef0f2;
    border-color: #33373d;
  }
}

Icon tone

Same rule applies to a simple UI element — a status swatch — so you can see the pattern holds beyond text and backgrounds.

.swatch.a, .swatch.b {
  width: 64px;
  height: 64px;
  border-radius: 10px;
  background: #f4f4f5;
  border: 1px solid #d8d8dc;
}

@media (prefers-color-scheme: dark) {
  .swatch.b {
    background: #1c1e22;
    border-color: #33373d;
  }
}
Browser support: all evergreen browsers (Chrome 76+, Firefox 67+, Safari 12.1+, Edge 79+).
