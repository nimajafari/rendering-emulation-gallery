prefers-contrast

Detects whether the visitor has asked their system for more or less contrast than the default, so a page can strengthen borders and text contrast for them.

Checking…
Try it: open Chrome DevTools → More tools → Rendering → Emulate CSS media feature prefers-contrast, then switch between no-preference and more. The banner above updates live.

Body text & border weight

Both panels use the same muted text and hairline border by default. Only the right panel strengthens both under prefers-contrast: more.

Body copy at standard contrast.

Body copy at standard contrast.

.panel.a, .panel.b {
  color: #9aa2ab;
  border: 1px solid #262b31;
}

@media (prefers-contrast: more) {
  .panel.b {
    color: #eef0f2;
    border: 2px solid #eef0f2;
  }
}

Button outline

Same pattern applied to an interactive control — a thin, low-contrast outline by default, thickened and darkened on request.

.btn.a, .btn.b {
  border: 1px solid #454b53;
}

@media (prefers-contrast: more) {
  .btn.b {
    border: 2px solid #eef0f2;
    font-weight: 600;
  }
}
Browser support: Chrome/Edge 96+, Firefox 101+, Safari 14.1+ (values: no-preference, more, less, custom).
