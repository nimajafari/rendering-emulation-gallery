prefers-reduced-motion

Detects whether the visitor has asked their system to minimize non-essential animation, so a page can cut or simplify motion for them.

Try it: open Chrome DevTools → More tools → Rendering → Emulate CSS media feature prefers-reduced-motion, then switch between no-preference and reduce. The banner above updates live.

Looping attention animation

Both boxes pulse by default. Only the right box's animation is disabled under prefers-reduced-motion: reduce.

.pulse.a, .pulse.b {
  animation: pulse 1.6s ease-in-out infinite;
}

@media (prefers-reduced-motion: reduce) {
  .pulse.b {
    animation: none;
  }
}
