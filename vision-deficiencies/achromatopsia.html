Achromatopsia

Total color blindness — the visitor sees only in shades of gray. There is no CSS media feature or JS API for this; it's a display filter DevTools applies over the whole page, so compare the two patterns below by eye while toggling it.

Try it: open Chrome DevTools → More tools → Rendering → Emulate vision deficiencies → Achromatopsia.

Bad: legend relies on hue only

Three bars distinguished only by hue at the same lightness. Under achromatopsia they collapse into a single shade of gray.

Good: pattern, brightness, and labels

Same three series, now differentiated by fill pattern and direct labeling, plus enough lightness contrast to read even in grayscale.
