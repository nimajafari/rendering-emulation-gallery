Blurred vision

Simulates low visual acuity — uncorrected refractive error, cataracts, or general low vision. There is no CSS media feature or JS API for this; it's a display filter DevTools applies over the whole page, so compare the two patterns below by eye while toggling it.

Try it: open Chrome DevTools → More tools → Rendering → Emulate vision deficiencies → Blurred vision.

Bad: small text, thin strokes

Fine print and hairline icon strokes that are already near the limit of legibility — blurring pushes them past it.

Delivery estimate: 3–5 business days from ship date, excluding weekends and public holidays.

Good: larger text, heavier strokes, more spacing

Same content, set at a larger size with a heavier icon stroke and generous line spacing — still readable when blurred.

Delivery in 3–5 business days.

DevTools note: this filter renders on top of the page — it cannot be detected or reacted to with CSS or JavaScript. The only real fix is sizing text and strokes generously by default.
