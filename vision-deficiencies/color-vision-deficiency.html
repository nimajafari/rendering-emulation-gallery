Color vision deficiency

Covers protanopia (red-weak), deuteranopia (green-weak), and tritanopia (blue-weak) — the three most common forms of color blindness. There is no CSS media feature or JS API for this; it's a display filter DevTools applies over the whole page, so compare the two patterns below by eye while toggling it.

Try it: open Chrome DevTools → More tools → Rendering → Emulate vision deficiencies, then pick Protanopia, Deuteranopia, or Tritanopia. Watch what happens to each pattern below.

Bad: color is the only signal

Status is conveyed purely by red vs. green hue. Under any red-green color deficiency, these become nearly indistinguishable.

Good: color plus shape and label

The same statuses now carry an icon shape and a text label, so meaning survives even when the color channel is unreliable.
