Reduced contrast vision

Simulates low-contrast perception, common with cataracts and other vision conditions. There is no CSS media feature or JS API for this; it's a display filter DevTools applies over the whole page, so compare the two patterns below by eye while toggling it.

Try it: open Chrome DevTools → More tools → Rendering → Emulate vision deficiencies → Reduced contrast.

Bad: text fails WCAG contrast

Muted-gray-on-dark body text at roughly 2.3:1 — already below the WCAG AA minimum of 4.5:1 for body text, so the reduced-contrast filter makes it nearly unreadable.

This paragraph uses #55595f on #16191d, well under the WCAG AA threshold for normal text.

Good: text meets WCAG AA contrast

Same layout, with body text at roughly 12:1 against the panel background — comfortably above the 4.5:1 minimum, so it stays legible under the filter.

This paragraph uses #eef0f2 on #16191d, comfortably above the WCAG AA threshold for normal text.

DevTools note: this filter renders on top of the page — it cannot be detected or reacted to with CSS or JavaScript. The only real fix is meeting WCAG AA contrast ratios (4.5:1 for body text, 3:1 for large text) by default.
